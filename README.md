# GitHub Pages site

This folder contains a static multi-page portfolio site for GitHub Pages.

## Structure
- `index.html` → main landing page
- `projects.html` → all-projects index
- `projects/*.html` → one page per project
- `style.css` → shared styling

## Publish
1. Create a repository named `himynameisfuego.github.io`
2. Upload all files from this folder to the root of the repository
3. Commit to the `main` branch
4. GitHub Pages will serve the site at `https://himynameisfuego.github.io`

## Easy edits
- Change the wording in `index.html` if you want a different personal brand angle.
- Add screenshots by placing images in an `assets/` folder and linking them from the project pages.
- Replace placeholder “Good additions later” sections with real demos, GIFs, or publication links.
